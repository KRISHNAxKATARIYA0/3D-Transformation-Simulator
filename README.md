
# 3D Transformation & Projection Simulator

An interactive 3D Computer Graphics application developed using Python, Pygame, and NumPy.

## Features

- 3D Translation along X, Y and Z axes
- 3D Rotation around X, Y and Z axes
- 3D Scaling
- Composite 3D Transformations
- Perspective Projection
- Orthographic Projection
- Interactive 3D Cube Visualization
- Reset functionality

## Technologies Used

- Python 3.11
- Pygame
- NumPy

## Installation

Clone the repository:

```bash
git clone YOUR_REPOSITORY_URL
```

Navigate into the project:

```bash
cd 3D-Transformation-Simulator
```

Install dependencies:

```bash
pip install -r requirements.txt
```

## Run the Application

```bash
python main.py
```

## Keyboard Controls

| Key | Function |
|---|---|
| Arrow Keys | Rotate X and Y |
| Q / E | Rotate Z |
| W / S | Move Z |
| A / D | Move X |
| I / K | Move Y |
| + / - | Scaling |
| ESC | Exit |

## Projection Modes

- Perspective Projection
- Orthographic Projection

## Academic Purpose

Developed as a Computer Graphics laboratory project to understand 3D transformations, homogeneous coordinates, transformation matrices, and projection techniques.
